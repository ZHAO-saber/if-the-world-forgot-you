# 如果世界忘记了你

一件可探索的交互网页作品。

林夏去世了。系统收到删除她全部数字痕迹的请求，AI 已自动删除 31,200 个文件，剩下 8 个被标记为「需要人工确认」。你是那个负责确认的人。

开场三行字：

```
林夏 · 1993 — 2026 · 数字遗产清除
系统已自动清除 31,200 个文件，剩余 8 个需要人工确认
按住，删除。
```

- **按住 = 删除**：照片开始反向显影，颜色先褪，细节再丢，最后被纸纹吞没；声音被捂住、往远处退。
- **松手 = 放过**：没删完就松手，它会在 1.5 秒里慢慢重新显影回来——像药水里的照片浮上来。
- 删到第 7 个之后，系统会告诉你：**这份删除请求是她自己两年前设的定时请求**——「如果我走了，请删掉我，别让他们难过。」
- 第 8 个文件删不完。松手，是作品唯一的结局方式；结局会明说**为什么删不完**：`删除未完成：2,417 处痕迹在别人的记忆里`。

## 运行

**双击 `index.html` 即可。** 原生 JS + WebGL2，没有任何外部依赖、没有 CDN、没有素材文件，断网也能跑。

（如果你的浏览器对 `file://` 有限制，也可以在目录里起一个静态服务器：`python -m http.server 8123`，然后打开 http://127.0.0.1:8123/ 。）

推荐 Chrome / Edge / Safari 新版。第一次按住会解锁音频（iOS 必须由手势解锁）。

## 操作

| 动作 | 方式 |
|---|---|
| 按住删除 | 鼠标左键按住 / 单指按住 / 键盘空格按住 |
| 松手放过 | 松开即可 |

多指时只认第一根手指；切到后台视为松手。移动端已禁用长按菜单、文字选择与双击缩放。

## 技术

- **反向显影着色器**：WebGL2 单 pass。三段交叠——脱色（银盐的灰偏棕）、真实降低信息量（`textureLod` 提升 mip 层级 + 对比塌陷）、域扭曲的纸纹潮水从四角吃进来，最后用细颗粒收尾。空间噪声全部预烘焙进一张 4 通道场纹理，片元着色器只做取样与算术。不是透明度渐变。
- **画面**：8 张 1024×1408 的相纸全部用 Canvas2D 程序化绘制（木纹、蛋黄、墨迹波形、打字、烛光、手写搜索、黄伞、玩具钢琴），带银盐颗粒、晕影、漏光与药膜软边；启动时分帧烘焙成纹理。
- **声音**：全部 Web Audio 实时合成。粉噪、雨、隔门欢呼、闹钟、键盘、木质吱呀、纸落、玩具钢琴（正弦+三角+×2.01 失谐 + 不和谐泛音）、48/55.5Hz 的低频嗡声。第 8 个文件的错音（第二句最高音 D5 弹成 D♯5）在按住时被系统用 320ms 的滑音「修好」，松手再滑回去。
- **性能**：所有程序化图像启动时烘焙，运行时不重绘；`devicePixelRatio` 上限 2；2560×1600 下实测仍被 vsync 卡在 165fps。
- **无障碍**：尊重 `prefers-reduced-motion`（关掉相机呼吸与漂移，保留褪色）；页面不可见时暂停计时与音频。
- **记忆**：看过的观众再次打开会直接进入白色画面，左上角「剩余：1」，那首歌在很远的地方轻轻响着。
- **结局的四种「消失」**：照片先溶回纸里（不是压暗成一块灰），纸再从中心那点烛光往外烧白；2,417 粒痕迹从漂移变成落定，最后一颗停在问题那一行旁边；问题停留很久之后极慢地淡到 0.55 就不再褪。白光里她会再出现一次——不是照片，是**压痕**（对模糊后的画面求梯度，只留轮廓，像纸记住了她）。然后是很长一段安静，安静里响起**她弹错的那个音**，一次，然后消散。

## 结构

```
index.html          入口（classic script，file:// 可直接运行）
css/style.css       排版、触摸与选择禁用
js/core.js          调色板 / 缓动 / 噪声 / 随机
js/melody.js        《生日快乐》音符表与那个错音
js/paper.js         程序化相纸、4 通道噪声场
js/art.js           8 个文件的程序化视觉与动态层
js/audio.js         全部声音合成与调度
js/shaders.js       反向显影着色器
js/gl.js            WebGL2 合成（含 2D 降级）
js/layers.js        纸堆 / 落纸 / 数据碎片 / 结局灰尘
js/input.js         Pointer / 键盘 / 多指 / 前后台
js/story.js         状态机、文案、时间轴
js/main.js          布局、相机呼吸、主循环、调试钩子
```

`SPEC.md` 是工程契约；`dev/` 是各模块的自测页；`tests/` 是真浏览器验收脚本；`preview/` 是成品关键帧。

## 验收

15 条断言全部通过（Edge 157，Playwright 真实鼠标 / 触摸 / CDP 驱动，170 秒跑完）：

```
$env:NODE_PATH=(npm root -g).Trim()
node tests/run-all.mjs
```

逐条实测值与证据截图见 `tests/RESULTS.md`、`tests/shots/`。其中几条值得记下的数字：

- 中途松手：按住 0.9s 时进度 0.314，松手 1.6s 内回到 0.000；卡片亮度按住期间单调 +14.9、松手单调 −14.8（无回退、无反弹）。
- 第 8 个文件按住 25 秒，进度仍只有 0.9535 —— 永远到不了 1。
- 结局：e1 / e2 / 系统日志 / e3 分别在第 8.73 / 11.41 / 12.65 / 14.61 秒浮现，全屏平均亮度 254.7（白），最后那一问 23.92 秒才出现（比第三行晚 9.31 秒），「重新开始」在 31.86 秒才亮起 —— 中间全是可以坐得住的空白。
- 错音：离线 FFT 峰值 621.09 Hz（D♯5），被"修复"后 585.94 Hz（D5），差 35 Hz —— 耳朵能听出来。
- 断网 / `file://` 直开 / 移动端竖横屏都能跑；零外部请求。
- 2,560×1,600 分辨率下仍被 vsync 卡在 165fps（真实 GPU，非软件渲染）。
